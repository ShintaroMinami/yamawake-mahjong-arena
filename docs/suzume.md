# suzume：教師に合わせた MLP で判断するボット

suzume は、強化学習で得た強いエージェント（教師）の方策を、判断ごとの小さな MLP に蒸留した軽量のボットです。教師は arena で大量に対局させるには遅いので、教師に近い強さで速く打てる相手を作ることを目的にしています。

- コード：[`src/rust/suzume/`](../src/rust/suzume/)（Rust）、[`src/python/yamawake/suzume.py`](../src/python/yamawake/suzume.py)（Python からの入口）
- モデルと固定のパラメータ：[`params/`](../params/)（ビルドのときに埋め込む）
- 学習のスクリプトとデータは、このリポジトリに含めていません。

## 1. 使い方

``` bash
uv run yamawake-arena --mode 2v2 --players suzume rulebot
uv run yamawake-arena --mode 1v3 --players suzume-mlp1:call=0 rulebot
```

``` python
from yamawake import SuzumeAgent
agent = SuzumeAgent({"riichi": 0})
```

### モデルの組

| モデル | 手組み | 状態予測 | 特徴 |
|---|---|---|---|
| `suzume`（= `suzume-mlp3`） | `flat_mlp3` | `normal_mlp3` | 規定 |
| `suzume-mlp3-flat` | `flat_mlp3` | `flat_mlp3` | 状態予測も東 1 局で学習（点数状況を見ない） |
| `suzume-mlp3-avoid4` | `normal_mlp3` | `normal_mlp3` | 手組みも点数状況を見る。ラスが減る |
| `suzume-mlp1` | `flat_mlp1` | `normal_mlp1` | 1 層の軽量版（局・トップ・親でスコアを補正） |
| `suzume-mlp1-flat` | `flat_mlp1` | `flat_mlp1` | 1 層、状態予測も東 1 局で学習 |

名前は学習データ（`flat` 東 1 局、`normal` 東南の半荘）と隠れ層の数（`mlp1` 1 層、`mlp3` 3 層）を表します。手組みは `params/hand/<組>/`、状態予測は `params/state/<組>.json` にあります。

### オプション

| オプション | 意味 | 既定 |
|---|---|---|
| `kan` | 0/1：カンする | 1 |
| `call` | 0/1：チー・ポンする（大明槓は `kan` に従う） | 1 |
| `riichi` | 0/1：立直する | 1 |
| `pf` | 0/1：押し引きの状態を予測して打ち分ける（3 節） | 1 |
| `fold` | 0/1：他家の立直に常にベタオリする（`pf=0` のときだけ） | 1 |
| `fold_shanten` | 0〜8：`fold=1` でベタオリに入る、打牌後の最小向聴 | 1 |

これ以外の値（DP の定数など、モデルが学習の前提にした値）はオプションにせず、[`params/suzume.json`](../params/suzume.json) に固定しています。

## 2. 判断の仕組み

判断ごとに次のルールを上から試し、最初に答えたものが打ちます（[`src/rust/suzume/registry.rs`](../src/rust/suzume/registry.rs)）。

1. 和了できれば和了する。九種九牌は流局にする。
2. 押し引き（`pf=1`）：自分の打牌で状態を予測し、M・F ならその状態のモデルで切る（3 節）。
3. カン：カンの MLP が、本来の選択よりカンを高く評価したときだけカンする。
4. 打牌・立直・副露：判断ごとの MLP で選ぶ。
5. 合法な打牌が 1 つしかなければそれを切る。

判断ごとの MLP は、打牌（向聴 1〜2、3 以上、立直できない聴牌）、立直、副露、カンの 6 種類です。判断の各選択肢を、全判断で共通の特徴量（76 列、[`src/rust/suzume/universal.rs`](../src/rust/suzume/universal.rs)）の 1 行で表し、MLP のスコアが最大の選択肢を選びます。特徴量の中心は、一人麻雀の DP（[`src/rust/eval/dp.rs`](../src/rust/eval/dp.rs)）による選択肢の後の手の価値（和了率・聴牌率・期待値）です。これに向聴と受け入れ、待ち、役の道、動かす牌の性質、同じ判断の中の比較を加えます。

## 3. 押し引き

自分の打牌ごとに、押す（P）・回す（M）・オリる（F）の状態を予測し、状態ごとのモデルで打ちます（[`src/rust/suzume/pf.rs`](../src/rust/suzume/pf.rs)）。

| 判断 | P | M | F |
|---|---|---|---|
| 打牌 | 手組みの MLP | 回し打ち（`discard_M`） | ベタオリ（`discard_F`） |
| 立直 | `riichi_P` | `riichi_M` | `riichi_M` |
| チー・ポン | `call_P` | `call_M` | `call_F` |
| カン | `kan` | `kan` | しない |

- **状態予測**：危険度の特徴量を他家 3 人 × 合法な牌種の行ごとに MLP に通し、平均と最大でまとめて P・M・F の確率を出します。確率が最大の状態を使います。`normal_*` は、局、本場、順位、点差などの点数状況（21 個）も読みます。副露の判断は、直前の自分の打牌の状態を使います。
- **ベタオリ・回し打ち**：牌種ごとに、他家 3 人それぞれへの危険度を MLP で採点し、ソフトな最小（−τ log Σ exp(−s/τ)）でまとめます。最高の牌種を切ります。特徴量（38 個）は、現物か、放銃パターン数（両面・嵌張・辺張・双碰・単騎）、河の読み（早い外側・宣言牌のスジ）、他家の副露と見え方、自分の手の損、残る安全牌です。

## 4. 学習

- 教師（RLActor-225、鳴きあり）×4 の対局で、各判断の教師の方策に合わせて学習しました（交差エントロピー）。
- P・M・F の状態は、教師の打牌に当てた HMM の事後確率で決めます。各状態のモデルは、その状態の事後確率で重みを付けた行で学習しました。状態予測は、その事後確率を目標に学習しています。
- データは、`flat_*` が東 1 局 10 万局、`normal_*` が半荘です。どちらもランダム牌山（split なし）で、対局ごとに 7 : 2 : 1（train・valid・test）に分けました。

## 5. 強さ

### 対 rulebot

2v2 対 rulebot（標準牌山の先頭 2,000 枚、2026-10-14）。値は suzume 側の 1 半荘あたりの平均です。天鳳の順位点は +90 / +45 / 0 / −135、ウマ 10-30 はオカ 20 の素点とウマ（1,000 点単位）です。

| モデル | 平均順位（SE 約 0.009） | 天鳳の順位点（SE 約 0.7） | ウマ 10-30（SE 約 0.36） |
|---|---|---|---|
| `suzume-mlp3` | 2.3609 | +10.72 | +5.50 |
| `suzume-mlp3-flat` | 2.3523 | +11.44 | +5.90 |
| `suzume-mlp3-avoid4` | 2.3548 | +11.45 | +5.34 |
| `suzume-mlp1` | 2.3702 | +9.90 | +5.10 |
| `suzume-mlp1-flat` | 2.3653 | +10.29 | +5.38 |

### suzume のモデル同士

2v2 の直接対決（標準牌山 5,000 枚。`suzume-mlp1` は 2,000 枚）。平均順位は左 / 右のモデルの値で、σ は牌山ごとの対の差をその SE で割ったものです。

| 組み合わせ | 平均順位 | 天鳳の順位点（左） | ウマ 10-30（左） |
|---|---|---|---|
| `suzume-mlp3` 対 `suzume-mlp3-flat` | 2.4891 / 2.5109（2.6σ） | +0.77（2.3σ） | +0.28（1.9σ） |
| `suzume-mlp3` 対 `suzume-mlp3-avoid4` | 2.4932 / 2.5068（1.3σ） | −0.04（0.1σ） | +0.65（3.2σ） |
| `suzume-mlp3` 対 `suzume-mlp1` | 2.4894 / 2.5106（1.3σ） | +0.94（1.5σ） | +0.39（1.3σ） |

3 層の組は 1 層の組より強い向きです。`suzume-mlp3-avoid4` は 1 位とラスが減ります。そのため天鳳の順位点では他と同等ですが、素点とウマでは下がります。
